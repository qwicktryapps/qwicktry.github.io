Privacy

Slot Scout doesn't run a server and doesn't track you. Everything it knows about you stays in your browser.

Version 1.0.0

The short version

Nothing you type is sent anywhere except ais.usvisa-info.com — the site you're already signed in to. There's nowhere else for it to go. The person who made this extension can't see your data, because it never leaves your computer.

What is stored, and where

All of the following is kept in your browser's local extension storage. It is readable only by this extension, on this browser profile, on this device.

Data Why
Email address To fill the AIS sign-in form and show who is signed in.
Password (only if you ask) To sign back in when the site logs you out. This is off by default. It's saved as plain text, the same way your browser saves passwords, and you can delete it any time with Forget my login in the side panel.
Appointment ID and current date To know which booking to improve on, and what counts as earlier.
Locations, date window, interval, auto-book Your settings.
Check counts and timestamps To show status and to back off correctly after a block.

What is sent over the internet

Two things, both to ais.usvisa-info.com, both using the login you already signed in with:

  • Reading the appointment calendar — the same requests the site's own page makes when you browse dates by hand.
  • Submitting the reschedule form, when a slot inside your window is found.

There are no requests to any other host. The extension declares no other host permissions, so it is not technically capable of contacting one.

What Slot Scout does not do

No tracking, no analytics, no crash reports. No screenshots. No ads. Your appointment details are never shared with other users or pooled with theirs. Nothing is sold, because nothing is collected in the first place.

Permissions, and why each one exists

Permission Used for
ais.usvisa-info.com The only site the extension runs on or talks to.
storage Saving your settings locally.
scripting Adding the interface and automation to AIS pages.
notifications Telling you a slot was found when auto-book is off, so you can decide without watching the tab.
sidePanel The settings and status panel.
cookies Clearing the stale AIS session cookie when the site gets stuck on its maintenance page. Only that one cookie, only on that one domain.
tabs Knowing which tab holds the watch, so a second tab does not check in parallel and get you blocked twice as fast.

Deleting your data

Reset everything in the side panel clears all saved data, including your login. Uninstalling the extension removes it too — Chrome deletes extension storage when you uninstall. Neither needs to contact anyone, because there is nowhere else a copy could be.

Children

Slot Scout is a tool for managing a visa appointment and is not directed at children. It collects nothing from anyone.

Changes

If a future version ever changes what is stored or sent, this page ships with the extension and will be updated in the same release. The version number at the top tells you which build a given copy of this page describes.
